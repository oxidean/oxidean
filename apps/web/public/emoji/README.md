# Emoji assets

Reaction glyph art, vendored so emoji render identically on every platform
(GitHub does the same — reactions are served images, never OS-font text).

- Source: [googlefonts/noto-emoji](https://github.com/googlefonts/noto-emoji) `svg/` tree
- Version: `v2.047`
- License: Apache-2.0
- Naming: `emoji_u<codepoint>` lowercased, without the `emoji_u` prefix (`1f44d.svg` = 👍).

Add glyphs by downloading the same naming pattern from the upstream tag above.
