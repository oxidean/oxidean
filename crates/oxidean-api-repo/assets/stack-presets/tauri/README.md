# Tauri 2

Vite frontend + `src-tauri` Rust shell (`npm create tauri-app` style).

## Getting started

```bash
npm install
npm run tauri dev
```

Requires the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/) (Rust toolchain, platform WebView).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Frontend only (Vite) |
| `npm run tauri dev` | Full desktop app |
| `npm run tauri build` | Production bundles |
