# Vue 3 (Vite + TypeScript)

Vite `vue-ts` template shape (`npm create vite@latest -- --template vue-ts`).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite + Vue HMR |
| `npm run build` | `vue-tsc` + Vite build |
| `npm run preview` | Preview production build |
