# Ripple

Vite + Ripple (`.tsrx`) starter.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite + Ripple HMR |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
