# Angular

Angular CLI application shape (`ng new` standalone + routing).

## Getting started

```bash
npm install
npm start
# or
npm run dev
```

Open http://localhost:4200

## Scripts

| Command | Description |
|---------|-------------|
| `npm start` / `npm run dev` | `ng serve` |
| `npm run build` | Production build |
| `npm test` | Karma / Jasmine unit tests |
