# SolidJS (Vite + TypeScript)

`vite-plugin-solid` starter (degit/create-solid style).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite + Solid HMR |
| `npm run build` | Typecheck + Vite build |
| `npm run preview` | Preview production build |
