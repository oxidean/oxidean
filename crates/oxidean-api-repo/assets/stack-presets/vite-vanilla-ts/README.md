# Vite + Vanilla TypeScript

Official Vite `vanilla-ts` template shape.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite dev server |
| `npm run build` | `tsc` + Vite build |
| `npm run preview` | Preview production build |
