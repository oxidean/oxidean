# Octane

Vite + Octane (`.tsrx`) starter — first-party Oxidean UI runtime.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:5173

Docs: https://octanejs.dev/

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Vite + Octane HMR |
| `npm run build` | Production build |
| `npm run preview` | Preview production build |
