# Astro

Official-style Astro starter (`npm create astro@latest` minimal TS shape).

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:4321

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Astro dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |
