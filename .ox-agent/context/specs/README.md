# Specs

Chronological record of spec'd work for this product. Active work runs
through **ox-agent work items** (`ox-agent start`, then the
discovery → specification → planning → implementation stages) with
artifacts tracked under `.ox-agent/work/`; the folders below are the
historical spec documents, imported for provenance and kept read-only.

Records dated before the ox-agent migration (2026-11-08) were authored
under the Agent OS framework (`YYYY-MM-DD-HHMM-<slug>/` folders with
`shape.md`, `plan.md`, `standards.md` when applicable, `references.md`).
Records dated before the Agent OS migration (2026-10-30) are imports of
prior spec-framework work — the v1.0 GSD milestone and the AI-DLC
intents. Their `plan.md` files summarize what shipped; full per-stage
artifacts stay read-only under [`_archive/`](_archive/) (`gsd/` phase
records, `aidlc/` intent records, `agent-os-migration-plan.md`).
