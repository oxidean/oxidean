**Motion 2 — Section reveal** (once, opacity + 12px rise) on the dual-mode and pillars bands: add `oct-reveal` to both sections and flip them to `oct-reveal-in` with a single `IntersectionObserver` (threshold `0.15`) that unobserves each element after it fires and disconnects on cleanup (T-03-11).

```css
.oct-reveal { opacity: 0; transform: translateY(12px); transition: opacity 320ms ease-out, transform 320ms ease-out; }
.oct-reveal-in { opacity: 1; transform: translateY(0); }
```

```tsx
useEffect(() => {
  const nodes = Array.from(document.querySelectorAll<HTMLElement>(".oct-reveal"));
  if (typeof IntersectionObserver === "undefined") {
    nodes.forEach((n) => n.classList.add("oct-reveal-in"));
    return;
  }
  const io = new IntersectionObserver(
    (entries) => {
      for (const entry of entries) {
        if (!entry.isIntersecting) continue;
        entry.target.classList.add("oct-reveal-in");
        io.unobserve(entry.target);
      }
    },
    { threshold: 0.15 },
  );
  nodes.forEach((n) => io.observe(n));
  return () => io.disconnect();
}, []);
```

**Motion 3 — CTA hover**: already delivered by the `transition-[background-color,border-color,color,filter] duration-150` base class on `Button` / `buttonVariants` from 03-01. Do not add a second hover animation, and do not add any looping/pulsing effect anywhere.

**Reduced motion** — append to the same `<style>` block so all three are neutralized (D-25, UI-SPEC "Reduced motion"):

```css
@media (prefers-reduced-motion: reduce) {
  .oct-rise { animation: none !important; }
  .oct-reveal, .oct-reveal-in { opacity: 1 !important; transform: none !important; transition: none !important; }
}
```

The `IntersectionObserver` still runs under reduced motion, but the CSS above makes both states visually identical, so content is never hidden from a reduced-motion visitor.
