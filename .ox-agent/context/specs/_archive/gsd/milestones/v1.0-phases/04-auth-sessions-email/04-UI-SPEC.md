## Visual hierarchy & layout contracts

### Shared auth shell (`/login`, `/signup`)

| Rule | Contract |
|------|----------|
| Chrome | Keep global `SiteHeader` + `SiteFooter` (same as Phase 3) |
| Page column | Centered; **max-w-md** (`28rem`); page padding **3xl** vertical / **md** horizontal |
| Brand | `OxideanMark` **48×48** above title — **no** duplicate “Oxidean” wordmark in the panel (header already brands) |
| Title | Heading role (24 / 600 / 1.2 Sora) |
| Support | One Body muted sentence under title |
| Surface | Editorial — **no marketing card grid**. Optional single `bg-card` panel with `border-border` + `rounded-md` + **lg** padding **only** if it improves form contrast on busy atmospheres; default is flat on `--background` |
| Atmosphere | Soft cool↔warm radial mesh allowed behind column (same language as landing; atmospheric only) |
| Cross-links | Label-size text under form: Login ↔ Signup; no “Forgot password” |
| Loading | Primary submit shows disabled + “Working…” label (or spinner icon in button); do not blank the page |

### Mode-exclusive provider UI (D-16) — locked

UI mode comes from public `auth.provider_config` (mode: `local` \| `workos` \| `oidc`). **Never** show local email/password fields when mode ≠ `local`. **Never** show WorkOS and OIDC CTAs together.

| Mode | `/login` | `/signup` |
|------|----------|-----------|
| **`local`** | Email-or-username + password + Remember me + **Sign in** | Email + username + password (+ confirm) + **Create account** |
| **`workos`** | Oxidean chrome + single primary CTA **Continue with WorkOS** → API start URL | Same CTA copy; title “Create your account”; body notes SSO via WorkOS |
| **`oidc`** | Oxidean chrome + single primary CTA **Continue with SSO** → API start URL | Same CTA; title “Create your account”; body notes enterprise SSO |

**SSO panel chrome:** Mark 48 + Heading + Body + one full-width primary Button (≥44px). No IdP logo soup. No secondary consumer OAuth buttons.

**Error banner (forms):** Muted destructive text block above fields (`text-destructive`, Label/Body) — problem + next step; not a toast-only path for first failure.

### `/login` fields (`local`)

| Field | Control | Notes |
|-------|---------|-------|
| Email or username | `Input` | `autocomplete="username"`; placeholder “Email or username” |
| Password | `Input` `type="password"` | `autocomplete="current-password"` |
| Remember me | Checkbox + Label | Extends session (backend TTL); default **unchecked** |
| Submit | Button `default` | **Sign in**; full-width on narrow |

### `/signup` fields (`local`)

| Field | Control | Notes |
|-------|---------|-------|
| Email | `Input` `type="email"` | `autocomplete="email"` |
| Username | `Input` | Handle; helper Label under field: “1–39 characters; letters, numbers, hyphen” |
| Password | `Input` `type="password"` | `autocomplete="new-password"` |
| Confirm password | `Input` `type="password"` | Client mismatch before submit |
| Submit | Button `default` | **Create account**; full-width on narrow |

**No** verification-gate messaging. Success → redirect per D-15.

### Post-auth redirect (D-15)

1. If `returnTo` query/state is a **safe same-origin path** and **not** `/` → go there  
2. Else → `/dashboard`  
3. Already signed-in visit to `/login` or `/signup` → redirect `/dashboard` (or `returnTo`)

### `/dashboard` (thin shell — RESEARCH discretion)

| Element | Contract |
|---------|----------|

| Body | Muted: “You’re signed in. Profile and admin tools live here until a fuller home arrives.” |

### `/settings/profile` (D-18)

| Element | Contract |
|---------|----------|
| Layout | max-w-xl content column under header; page title Heading **Profile** |
| Avatar | Squircle preview **64×64** (reuse mark clip language); **Change avatar** secondary/ghost control opens file picker; show filename/status Label on select |
| Fields | Display name (`Input`); Username (`Input`); Bio (`Textarea`, rows ~4, max length **160** chars — discretion) |
| Primary action | **Save profile** (`default` Button) |
| Session actions | Separator; **Log out** (ghost) = this device; **Log out all devices** (`destructive` text/outline Button) with confirm |

### `/admin/auth` (admin only)

| Element | Contract |
|---------|----------|
| Gate | Non-admin → redirect `/dashboard` or 403 page with Body “You need admin access.” |
| Title | Heading **Auth settings** |

| Primary action | **Save auth settings** |
| Destructive | None beyond mode switches (no delete-instance) |

| Token | Value | Usage |

| sm | 8px | Field↔helper gap, compact control padding |

## Typography

**Inherited — exactly 4 sizes, 2 weights** (Phase 3 lock):

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Label | 14px | 400 | 1.4 | Source Sans 3 |
| Body | 16px | 400 | 1.5 | Source Sans 3 |
| Heading | 24px | 600 | 1.2 | Sora |
| Display | 40px | 600 | 1.15 | Sora |

**Weights used:** **400** and **600** only.

**Phase 4 application map:**
- Auth / dashboard / profile / admin page titles → **Heading**
- Field labels, helpers, ENV badges, menu items, button labels → **Label** (600 on primary/secondary CTA labels; 400 on ghost)
- Support copy, bio, errors body → **Body** (errors may use Label size with destructive color for density)
- **Display** unused on auth screens (reserved for marketing/status heroes)
