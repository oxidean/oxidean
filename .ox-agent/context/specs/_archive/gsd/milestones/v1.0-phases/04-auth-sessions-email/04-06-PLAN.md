<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser multipart → `/api/user/avatar` | Untrusted file bytes |
| Browser → `admin.auth.*` | Privilege boundary for instance auth config |
| Public GET `/uploads/avatars/*` | Public read of avatar bytes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-19 | Tampering | avatar upload path | mitigate | Ignore client filename; write only `{user_id}.webp` under `var/uploads/avatars`; reject `..`; cap body 2 MiB; decode via `image` crate then re-encode webp/jpeg |
| T-04-20 | Denial of service | image decode | mitigate | 2 MiB body limit + decode bounds; reject non-allowlisted content-types (`image/jpeg`,`image/png`,`image/webp`) |
| T-04-21 | Elevation of privilege | admin.auth.* | mitigate | Require session + `user.is_admin`; return `admin.forbidden` otherwise |
| T-04-22 | Information disclosure | auth settings | mitigate | Never return SMTP password / Resend key / WorkOS API key / OIDC secret in RPC — only booleans “configured via ENV” |
</threat_model>
