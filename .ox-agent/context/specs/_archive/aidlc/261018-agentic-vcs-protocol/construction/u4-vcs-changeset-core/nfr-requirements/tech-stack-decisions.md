# Tech-Stack Decisions — u4-vcs-changeset-core

## TD4.1 — Server dep additions (verified against Cargo.toml)

`server` feature gains: `dep:serde` + `dep:serde_json` (canonical recipe + index payloads — **absent from Cargo.toml under any feature**; both are workspace deps — `serde = { workspace = true }` (workspace serde already carries `derive`) + `serde_json = { workspace = true }` join the server feature list), `dep:base64` (cursor codec — pin api's `base64 = "0.23"`), `dep:hex` (key hashes — pin `hex = "0.4"`; absent workspace-wide, preferred over adding a ninth `bytes_to_hex` clone — eight exist today across api/object_store), `dep:oxidean-core` (`ChangesetId` — and the `ChangesetId::parse` oracle per SR4.3 — come from `oxidean_core::vcs_types`; domain `Ref` is a local entity shape, not a wire type — currently dev-deps only; joins `server` as optional so `client` stays dep-free). Already present server deps consumed verbatim: `sha2`, `chrono`, `tokio`, `futures-util`, `oxidean-db`, `tracing`. `cargo machete` ignored-list escape hatch applies if feature-gated deps false-positive (api Cargo.toml:106 precedent).

## TD4.2 — Module layout (server-gated)

`crates/oxidean-vcs/src/changeset_store.rs`, `ref_registry.rs`, `read_index.rs`, `text_diff.rs` — all under `#[cfg(feature = "server")]`; `text_diff` takes blob CONTENT (bytes/lines), not object-store handles — callers (`read_index` blame/diff, u5 merge) supply bytes from `ObjectStore::get` so the diff core stays IO-free and u5-consumable. Error enums live next to their components; the sentinel literals pin in `changeset_store`'s decode helper (Q7).

## TD4.3 — 0054 migration delta (sanctioned U2-delta, three-dir parity)

`crates/oxidean-db/migrations/{postgres,mysql,sqlite}/0054_vcs_key_collation.sql`: mysql/ carries the real ALTERs — every column gets explicit charset+collation+NOT NULL (`MODIFY COLUMN index_key VARCHAR(560) CHARACTER SET utf8mb4 COLLATE utf8mb4_bin NOT NULL` on `vcs_derived_index`; same `CHARACTER SET utf8mb4 COLLATE utf8mb4_bin NOT NULL` shape on `vcs_refs.name` and `vcs_file_changes.path` — bare `COLLATE` errors if the column charset isn't already utf8mb4, and the 0053 tables carry no explicit charset so the DB default governs). postgres/ + sqlite/ carry comment-only no-op files (PG equality is bytewise; SQLite BINARY default). Filename parity is enforced by the `migration_parity` test + FR15.5. Claimed under this unit's source manifest (U3's facade-addition precedent).

## TD4.4 — Hand-rolled ULID packing

No `ulid` crate in the workspace — `canonical_changeset()` packs `sha256(canonical_input)[0:16]` into the canonical 26-char uppercase Crockford body directly (128 bits MSB-first, alphabet `0-9 A-H J-K M-N P-T V-Z`, ~20 lines + unit test asserting `is_changeset_id` round-trip). Id is exactly `cs_`+26 chars — fits CHAR(29)/VARCHAR(32)/TEXT columns untouched.

## TD4.5 — Canonical recipe implementation shape

`canonical_changeset() -> {manifest_json, manifest_hash, canonical_input, idem_key, id}` — one function, fixed serde structs (`#[derive(Serialize)]` with declared field order; serde_json emits declaration order deterministically; optional fields `skip_serializing_if = "Option::is_none"` — never null). `manifest_json` is computed hash-material only — never persisted (no manifest column exists; only `manifest_hash` lands in the row, and `file_changes` rows carry the data). The recipe is pinned so U5/U6 reproduce bytes identically. Deviation register: `repo` inside canonical_input (global id PK requires it) — recorded in FD Q1.

## TD4.6 — Time + determinism seams

`CreateChangesetInput.committed_at: Option<String>` is the clock injection (tests pass `Some`; production passes `None` → `Utc::now()` normalized to `%Y-%m-%dT%H:%M:%SZ`). `chrono` already a server dep; `SecondsFormat::Secs` emits the pinned shape. No `SystemTime`/`Instant` anywhere in the id path — `committed_at` is excluded from `canonical_input` (AC2.2.3).

## TD4.7 — Facade call discipline

Only the pinned C5 surface: `vcs_create_changeset_tx`, `vcs_get_changeset`, `vcs_changeset_parents`, `vcs_find_changeset_by_idem`, `vcs_list_file_changes`, `vcs_list_refs`, `vcs_cas_ref_update`, `vcs_delete_ref`, `vcs_upsert_derived_index_rows`, `vcs_query_derived_index`, `vcs_lookup_import_link`, `vcs_get_object` (sentinel-probe only). **Zero new facade methods** — ref point-reads are `vcs_list_refs` match-or-exhaustion scans; `vcs_get_ref` does not exist and is not added (R-05: early-stop is collation-unsafe anyway). Scan shapes: probes `index_key=Some, cursor=None`; scans `index_key=None, cursor=Some(start)`, terminate on prefix-break or exhaustion.

## TD4.8 — Test posture (NFR10 — same gate as TD3.7)

Feature-gated invocations (already pinned in CI/Makefile by U3): `cargo nextest run -p oxidean-vcs --features server` + `cargo clippy -p oxidean-vcs --all-targets --all-features` — zero-test runs are failures. sqlite-backed integration coverage: deterministic-id vectors (golden canonical bytes → id), idempotent resubmit same-id/one-row, concurrent identical creates (tokio::join — one row), concurrent same-parent divergent creates (distinct ids), missing parent/object → typed errors, ref CAS all outcome arms (create-only, move, delete, absent-delete → not_found, retried-CAS conflict, assert-absent noop), ref name rejection incl. id-shapes, log walk + skip-replay cursor (no cross-page dup on same-second commits), tree materialize (incl. crash-resume), path_history chronological + rename visibility, blame attribution (incl. rename chain), merge_base (linear→self, divergent, no-ancestor → typed error), file_at incl. delete-not-found, cursor malformed → invalid_input, DbNotConfigured — plus: `FrontierTooLarge` exercised via injected cap constants (never 250k fixtures); `text_diff` golden vectors (the shared module gets pinned correctness tests of its own); every SR4.1 validation arm (path grammar, author shape, corrected mode set, message/parents bounds, committed_at fractions/range, manifest uniqueness — `path` unique, `old_path` unique across manifest, `old_path≠path` per entry); sentinel non-match (`"vcs.not_found:parentXYZ"` → `Internal`, not a typed decode); object-links completeness (AC3.5.2 — every manifest blob linked); `payload.path==arg` guard (inject a mismatched row via `vcs_upsert_derived_index_rows`). Dialect honesty: the `db-dialects` CI lane executes the 0054 ALTERs on real MySQL 8.4 via `db.migrate()` — that proves syntax + PK-width acceptance only (migrate coverage). utf8mb4_bin *behavior* (case-variant coexistence, `>` keyset semantics) gets no execution there — pinned fix: `crates/oxidean-db/tests/dialect_vcs.rs` beside `dialect_probe.rs`, `DATABASE_URL`-gated skip-pass in the established `dialect_*` family idiom (assert `information_schema` collation = `utf8mb4_bin` + case-variant insert/read round-trip on mysql; executes locally/docker with a MySQL `DATABASE_URL`, skips green in the sqlite-only `vcs-server` leg — widening the `db-dialects -E` filter is an optional CI decision, not required); until it lands the gap is recorded in SR4.11.

## TD4.9 — Error channel

Three typed enums per entities.md (`ChangesetError`/`RefError`/`IndexError`) — `IndexError` variants: `NotFound`, `PathNotFound`, `BaseNotFound` (one name — the Q4 `NoCommonAncestor` mention is aliased to `BaseNotFound`), `FrontierTooLarge`, `CursorMalformed`, `InvalidInput`, `Internal`, `DbNotConfigured`. `From` impls for facade `String` errors (sentinel-exact match → typed, else `Internal`). u7 maps variants → wire codes; enums never self-stringify to wire data.
