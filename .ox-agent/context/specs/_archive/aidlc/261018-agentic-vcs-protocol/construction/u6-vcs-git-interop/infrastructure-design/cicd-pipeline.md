## U6 suite surface (all `#[cfg(all(test, feature = "server"))]` in `git_interop.rs`)

Fixtures: `testutil::test_db()` → `(TempDir, Database)` (TempDir held alive; never `:memory:`); real `git` repos under `tempfile::tempdir()` driven through `CliGitBackend` (cli.rs:3686 fixture precedent); a mock `ProtectionChecker` recording call order + returning canned `ProtectionBlockReasons`. **No new services.**

- **Cursor codec**: encode→decode round-trip; emitted opaque-string cap (`b64url.len() > cursor_payload_max_bytes` ⇒ `TooLarge` — the emit-side check, not the inner JSON); forged inputs → `ImportState` (bad b64, bad JSON, `v != 1`, `tips.len > cursor_tips_max`, non-40-hex/dash-led tip oid, >256-char tip name, `skip > len` — the devsecops-M1 bound BEFORE indexing, `last_oid` continuity mismatch); symmetric encode-side field rejection (>256-char name ⇒ `TooLarge`).
- **Claim/release**: foreign-`active` nonce ⇒ `ImportState`; TTL `import_lock_ttl_secs` stale reclaim; nonce-verified release (mismatch ⇒ silent skip); `ok` selects `idle`/`failed` terminal state, both release.
- **Import**: `import_one` on a seeded repo → changeset + `ident:`/`ident-cs:` sidecars + `linked:` row + import-link; insert-if-absent idempotence (re-import ⇒ early-skip, `imported` count honest); **divergent link arm** — insert returns `false` with stored cs `≠` ours ⇒ `Internal` (BR6.4's provenance guard, not just the same-id skip); non-commit tip peel ⇒ drop + `skipped_tips` count; `lazy_import` direct-tip bypass (a branch literally named the target 40-hex oid cannot shadow it); multi-page lazy loop (cursor carries; `page.done ∧ unlinked` ⇒ `Internal`); `is_git_oid` 40-only (64-hex rejected `InvalidInput`).
- **Export**: empty-set fast-path (no writes, no move); ordering assert via mock — objects written BEFORE `checker.check`, exactly ONE move after; two-phase ff gate (changeset-side link/ancestor probe, git-side `is_ancestor` fallback); unlinked non-ancestor old ⇒ `RefConflict{actual:None}` even under `force`; linked non-ancestor + force ⇒ proceed; linked non-ancestor + !force ⇒ `RefConflict{actual:Some}`; hook `Denied` ⇒ `Forbidden{reasons:["push_hook"]}` (no stderr); `Conflict` ⇒ `RefConflict` re-read link; same-anchor re-export no-op.
- **Refusal inventory** (SR6.7, deterministic — one arm each): >64-parent commit ⇒ `InvalidInput`; >65535-byte message ⇒ `InvalidInput`; unrepresentable/out-of-range timestamps ⇒ `InvalidInput`; path >512 chars/`..`/control-byte ⇒ `InvalidInput`; author `<`/`>`/empty/composed >255 ⇒ `InvalidInput` — every refused shape asserts NO changeset row was minted (fail-closed, no partial state).
- **`is_skipped` entry gate** (SR6.9, fail-closed): each of `import_chain`/`lazy_import`/`export` on a skipped database ⇒ `DbNotConfigured` typed at entry — before any git argv, claim, or facade call.
- **Error bridge**: one arm per consumed enum — `GitError` all six (`Denied`/`Conflict`/`NotFound`/`InvalidArg`/sentinel-`Process`→`TooLarge`/other-`Process`/`Io`→`Internal`), `IndexError` (`CursorMalformed`→`Internal`, `FrontierTooLarge`→`TooLarge`, `DbNotConfigured`), `ObjectStoreError` (`QuotaExceeded`/`DbNotConfigured`/7 others→`Internal`), `ChangesetError`, checker `Err`→opaque `Internal`, facade `String`→`Internal`; fixed messages carry no stderr/paths/rejected values.
- **Caps** (constructor-injected small `InteropCaps` — TD6.1 testability pin): `import_commit_cap` caller-limit/window over ⇒ **`InvalidInput`** (per SD6.6 — the limit bound is the one `InvalidInput` trip; traversal bounds below are `TooLarge`), `rev_list_max`/`cursor_tips_max`/`import_tree_max`/`export_chain_max`/`export_ancestor_probe_max`/`cursor_payload_max_bytes`/`import_blob_max`/`export_blob_max` each ⇒ `TooLarge`; `validate` trio (`blob_max > max_object_bytes`, `*_max > usize::MAX/2048`, zero cap ⇒ `InvalidInput`).
- **`oxidean-git` cli.rs additions** (same crate, same in-file style): `run_git_stdout_bounded` kill ⇒ `Process` carrying `oxidean:stdout-bound-exceeded`; `commit_name_status` `-z` rename order asserted `status\0src\0dst\0` (the empirical pin); `tree_flat`/`commit_name_status` `max_bytes` honored; `write_object`+`write_commit` (mktree -z, `{:06o}` modes, stdin message) round-trip via `cat_commit`; `check_refname` oracle; `verify_commit_oid` tag-peel/non-commit `None`; `fast_forward_ref`/`force_update_ref` `actor_capability` threaded (existing callers pass `"admin"` — call-site updates compile-checked).
- **`oxidean-db`** (dialect_vcs leg): NULL `covering_changeset` write → `Option::None` decode; non-NULL round-trip; 0055 replay on each dialect (sqlite table-rebuild vs pg/mysql `ALTER`).
- **`oxidean-core`**: `VcsGitImportHead.changeset_id: Option` absent-key + `skipped_tips` serde round-trip (wire-superset — absent key ⇒ `None`, never a decode break for u1's callers).
