### Summary

The provider subsystem is broadly faithful to the design — custody, SSRF literals/DNS, streaming semantics, auth scoping, persistence atomicity, boot degradation, and the U1 seam all verify cleanly — but it ships one merge-blocking defect: the write-path build arm drops the `resolved.enabled` conjunct, so a flag-off write that touches provider fields installs an enabled runtime slot while reporting `flag_off` to the admin (R-01, proven live). Three Minor issues accompany it: the unconditional settable guard wedges every `settings_set` under release+env-stub (R-02), IPv6 embedding prefixes bypass the egress bound on translated egress (R-03), and the `stub-1` sentinel leaks into status and live Ollama requests for model-less slots (R-04). Verdict NOT-READY until R-01 is fixed and regression-covered.
