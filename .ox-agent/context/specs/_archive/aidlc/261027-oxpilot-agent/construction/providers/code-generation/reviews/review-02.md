### Summary

All four iteration-1 findings are fixed and verified — the flag-off build arm now carries the `cfg.enabled` conjunct (R-01, regression-tested), payload-scoped validation unwedges env/stale-provider configs without losing write-chosen refusals (R-02), the v6 translation prefixes are blocked (R-03), and `stub-1` no longer fabricates onto status or the wire (R-04).
