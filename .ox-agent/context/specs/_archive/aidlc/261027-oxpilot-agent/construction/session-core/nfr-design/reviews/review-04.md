### Summary

The post-iteration-3 state is coherent at the architecture level — residence, caps plumbing, ownership pre-checks, drain tx, and the amended C5 block all hold up — but three C5-surface gaps remain where the contract's own artifacts disagree with themselves or go silent: `enqueue`'s return type cannot carry the pinned `position` field, the assistant-row write path is undecidable between port and direct-db (with the "service owns every store call" claim contradicting the direct reading), and `append_tool_call` has no pinned way to obtain the required `seq` copy.
