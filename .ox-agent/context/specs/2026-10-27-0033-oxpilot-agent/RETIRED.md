# Retired — ox-pilot removed from the product

This spec records the shipped ox-pilot feature (agentic chat + computer-use
connector, delivered via #203). The feature was removed product-wide in
issue #258: API crate, DB modules + tables (migration 0099), web routes,
`ox pilot` CLI, deploy env contract, and docs are all gone. This directory
and the AIDLC archive under `../_archive/aidlc/261027-oxpilot-agent/` are
kept as read-only provenance only — do not implement against them.
