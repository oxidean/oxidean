### Notes for the conductor (verified clean — no findings)

- The `classify` dispatch table matches BR2.3/BR8.3/BR8.4 exactly on the run loop: claim/heartbeat `not_found` → delete creds exit 0; report 404 → drop-and-continue; `disabled` → non-terminal backoff creds kept; `bad_input` → exit non-zero creds kept; `unauthorized`/off-pair `forbidden` → kill+delete+exit non-zero, no report; `revoked` → kill+report+delete+exit 0.
- Wire constants verified against shipped code: `OUTPUT_MAX=256*1024` (routes.rs), claim wait max 60 (`CLAIM_WAIT_MAX_SECS`), heartbeat 15s inside the 90s liveness window, pairing TTL 600s, `CLAIM_RETRY_AFTER_SECS=0`, claim batch `{actions,cancel,retry_after}`, `ClaimAction.args: String`, flat `{"error":code}` envelopes with all 10 codes mapped.
