<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `DATABASE_URL` / `OXIDEAN_DB_DIALECT` env → `oxidean-db` | Operator-supplied connection string containing credentials |
| `oxidean-db` → Postgres / MySQL / SQLite server or file | Connection handshake and pool lifecycle cross into the engine |
| Host filesystem `./var` → SQLite file | Process creates directories and a database file on the host |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure | connect/ping error strings | mitigate | `redact_url()` strips the password component; every `Err(String)` returned from resolve/connect/ping passes through it; unit test asserts a known password never appears in the error text. 02-02 extends the same treatment to migrate/probe/CLI output |
| T-02-04 | Information disclosure | SQLite file on host disk | accept | `./var/oxidean.db` inherits process umask; Phase 2 documents `var/` as runtime state and gitignores it (plan 02-04); filesystem hardening is an ops concern, no secrets stored in Phase 2 schema |
| T-02-05 | Denial of service | connection pool exhaustion | mitigate | `max_connections(5)` on Postgres/MySQL pools, `max_connections(1)` on SQLite (single-writer); no unbounded pool growth |
</threat_model>

2. New module `crates/oxidean-db/src/dialect.rs`:
   - `#[derive(Debug, Clone, Copy, PartialEq, Eq)] pub enum Dialect { Postgres, MySql, Sqlite }`
   - `pub fn as_str(self) -> &'static str` → `"postgres" | "mysql" | "sqlite"` (D-10 stamp value; this exact string is what lands in `instances.dialect` and in the RPC response).
   - `pub fn from_url(url: &str) -> Result<Self, String>` — prefix match only, never `url::Url::parse` (SQLite URLs are not RFC-3986): `postgres://` or `postgresql://` → Postgres; `mysql://` → MySql; `sqlite:` → Sqlite (covers `sqlite:`, `sqlite://`, `sqlite::memory:`); anything else → `Err(format!("unrecognized DATABASE_URL scheme: {}", redact_url(url)))`. Do **not** accept `mariadb://` (RESEARCH pitfall 6).
   - `pub fn parse_declared(value: &str) -> Result<Self, String>` for `OXIDEAN_DB_DIALECT` values `postgres|mysql|sqlite`, else `Err("unknown OXIDEAN_DB_DIALECT: {value} (expected postgres|mysql|sqlite)")`.
   - `pub fn resolve_dialect(url: &str, declared: Option<&str>) -> Result<Dialect, String>` — pure function (takes `declared` as an argument so tests never race on process env). On disagreement return exactly: `format!("OXIDEAN_DB_DIALECT={} does not match DATABASE_URL scheme (detected {})", declared.as_str(), from_url.as_str())` (D-02).
   - `pub fn resolve_dialect_from_env(url: &str) -> Result<Dialect, String>` — thin wrapper reading `OXIDEAN_DB_DIALECT` and delegating to `resolve_dialect`.
   - `pub fn redact_url(url: &str) -> String` — replace the password between the first `://user:` and the following `@` with `***` (T-02-01); URLs with no credentials are returned unchanged.
3. `src/lib.rs`: `pub mod dialect;` and `pub use dialect::{redact_url, resolve_dialect, resolve_dialect_from_env, Dialect};`. Delete the obsolete `connect_stub()` fn and its test.
4. Unit tests in `dialect.rs` (`#[cfg(test)] mod tests`), named so they are selectable by the VALIDATION commands:
   - `resolve_dialect_schemes` — table-driven over `postgres://u:p@h/db`, `postgresql://u:p@h/db`, `mysql://u:p@h:3306/db`, `sqlite:./var/oxidean.db`, `sqlite://./var/oxidean.db`, `sqlite::memory:`.
   - `resolve_dialect_unknown_scheme` — `mssql://x` and `mariadb://x` both `Err`.
   - `resolve_dialect_mismatch` — `resolve_dialect("postgres://u:p@h/db", Some("mysql"))` is `Err` and the message contains `does not match DATABASE_URL scheme`.
   - `resolve_dialect_agreeing_declared` — `Some("postgres")` with a `postgres://` URL is `Ok(Dialect::Postgres)`.
   - `redact_url_hides_password` — `redact_url("postgres://oxidean:hunter2@db:5432/oxidean")` does not contain `hunter2`.

```rust
#[derive(Clone)]
pub enum DbPool {
    Postgres(sqlx::PgPool),
    MySql(sqlx::MySqlPool),
    Sqlite(sqlx::SqlitePool),
}
```

   - `pub async fn connect(url: &str, dialect: Dialect) -> Result<DbPool, String>` matching on dialect:
     - Postgres: `PgPoolOptions::new().max_connections(5).connect(url)`
     - MySql: `MySqlPoolOptions::new().max_connections(5).connect(url)`
     - Sqlite: call `ensure_sqlite_parent_dir(url)?` first (D-18), then `SqliteConnectOptions::from_str(url)?.create_if_missing(true).journal_mode(SqliteJournalMode::Wal).foreign_keys(true)` and `SqlitePoolOptions::new().max_connections(1).connect_with(opts)` (D-20, T-02-05).
     - Every error maps through `.map_err(|e| format!("{}: {e}", redact_url(url)))` (T-02-01).
   - `pub fn ensure_sqlite_parent_dir(url: &str) -> Result<(), String>` — strip the `sqlite:` prefix, then any leading `//`, drop a `?`-query suffix if present, return `Ok(())` for `:memory:`; otherwise `std::fs::create_dir_all(parent)` when the parent is non-empty. sqlx's `create_if_missing` creates the *file* only — never the directory (RESEARCH pitfall 2).
   - `pub fn dialect_of(pool: &DbPool) -> Dialect`.
2. Rewrite `Database` in `src/lib.rs`:

```rust
#[derive(Clone)]
pub struct Database {
    pool: Option<DbPool>,
    dialect: Option<Dialect>,
}
```

   - `pub fn skipped() -> Self` unchanged in behaviour (both fields `None`) — keeps existing `oxidean-api` tests green with no `DATABASE_URL`.
   - `pub async fn from_env() -> Result<Self, String>`: when `DATABASE_URL` is set and non-empty, `resolve_dialect_from_env(&url)?` then `pool::connect(&url, dialect)?`; otherwise `Ok(Self::skipped())`.
   - `pub async fn connect(url: &str) -> Result<Self, String>` — same path with an explicit URL (used by tests and the migrate binary).
   - `pub fn dialect(&self) -> Option<Dialect>`.
   - `pub async fn ping(&self) -> &'static str` — keeps the `"ok" | "error" | "skipped"` contract consumed by `system.health`; runs `SELECT 1` against whichever pool variant is present.
3. `src/lib.rs`: `pub mod pool;` and `pub use pool::DbPool;`. Keep the crate doc comment accurate ("uniform adapter boundary; the only place dialect branching is allowed" — D-08).
