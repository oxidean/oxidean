<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Service worker → every same-origin request | The SW sits in front of all fetches, including future authenticated RPC traffic |
| Web manifest `start_url` / `scope` → OS launcher | Values become the entry point of an installed app |
| Generated icon assets → repo | Build-time binaries committed into the tree |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-16 | Information disclosure | SW caching API / auth responses | **mitigate (HIGH)** | Per D-30 the Workbox config is assets-only: `globPatterns` limited to `js,css,html,svg,png,ico,woff2`; `navigateFallbackDenylist: [/^\/api\//, /^\/health$/]`; and explicit `runtimeCaching` entries for `/api/` and `/health` with `handler: "NetworkOnly"`. Acceptance criteria grep the **generated** service worker for any precache entry or cache handler matching `/api` and fail if one exists — verifying the built artifact, not just the config |
| T-03-17 | Tampering / open redirect | manifest `start_url`, `scope` | mitigate | Both are the literal `"/"`; no value derived from request, referrer, or env. No `url_handlers`, no `share_target`, no protocol handlers are declared |
| T-03-18 | Denial of service | stale precached shell after deploy | mitigate | `registerType: "autoUpdate"` plus `cleanupOutdatedCaches: true` so a new build replaces the shell instead of pinning clients to an old bundle that talks to a newer API |
| T-03-19 | Injection (XSS) | inline SW-registration script | mitigate | The registration script is a static string literal containing a hardcoded `'/sw.js'` path with no interpolation, matching the T-03-04 rule already applied to the theme boot script |
| T-03-20 | Tampering | committed binary icon assets | mitigate | `scripts/gen-icons.sh` regenerates every icon from `brand/oxidean-mark.png` and the committed mask, so any asset can be re-derived and diffed rather than trusted blindly |
</threat_model>

Create `scripts/gen-icons.sh` (mode 0755) generating the D-20 icon set from `brand/oxidean-mark.png`, using the committed squircle mask so raster icons and the DOM mark share one silhouette (D-02).

```sh
#!/usr/bin/env bash
# Regenerates the Oxidean favicon / app-icon set from brand/oxidean-mark.png.
# Squircle silhouette comes from the same mask the DOM mark uses (D-02, D-20).
set -euo pipefail

cd "$(dirname "$0")/.."

SRC=brand/oxidean-mark.png
MASK=apps/web/public/brand/squircle.svg
OUT=apps/web/public
WORK="$(mktemp -d)"
trap 'rm -rf "$WORK"' EXIT

command -v magick >/dev/null || { echo "ImageMagick 'magick' is required" >&2; exit 1; }
test -f "$MASK" || { echo "missing $MASK — run: node scripts/gen-squircle.mjs" >&2; exit 1; }

mkdir -p "$OUT/icons"

# 1024 square source, then squircle-clipped master
magick "$SRC" -resize 1024x1024^ -gravity center -extent 1024x1024 "$WORK/square.png"
magick -background none "$MASK" -resize 1024x1024 "$WORK/mask.png"
magick "$WORK/square.png" "$WORK/mask.png" -alpha set -compose DstIn -composite "$WORK/squircle.png"

# Favicons + apple touch icon (squircle)
magick "$WORK/squircle.png" -resize 16x16   "$OUT/favicon-16.png"
magick "$WORK/squircle.png" -resize 32x32   "$OUT/favicon-32.png"
magick "$WORK/squircle.png" -resize 180x180 "$OUT/apple-touch-icon.png"
magick "$WORK/squircle.png" -resize 48x48   "$WORK/favicon-48.png"
magick "$OUT/favicon-16.png" "$OUT/favicon-32.png" "$WORK/favicon-48.png" "$OUT/favicon.ico"

# Manifest icons (squircle)
magick "$WORK/squircle.png" -resize 192x192 "$OUT/icons/icon-192.png"
magick "$WORK/squircle.png" -resize 512x512 "$OUT/icons/icon-512.png"

# Maskable icon: full-bleed on the dark brand surface with a safe zone, so the
# platform applies its own shape instead of double-rounding our squircle.
magick "$WORK/square.png" -resize 410x410 \
  -background '#0b0c0e' -gravity center -extent 512x512 \
  "$OUT/icons/icon-512-maskable.png"

echo "icons written to $OUT"
```

Run it and commit every produced file. If `magick` is unavailable in the execution environment, install ImageMagick or use `bunx --yes sharp-cli` for the resize/composite steps — the output filenames, sizes, and the squircle-vs-maskable distinction above are the contract, the tool is not.

Note for a later plan (do not act on it here): `apps/web/public/oxidean-mark.png` stays as-is because `OxideanMark` loads it at runtime.
