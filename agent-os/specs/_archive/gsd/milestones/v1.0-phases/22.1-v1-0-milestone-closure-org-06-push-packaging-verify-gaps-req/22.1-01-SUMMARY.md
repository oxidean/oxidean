**2. [Rule 1 - Bug] Postgres INT4 decode for review count**
- **Found during:** Task 1 Compose smoke (`repo.branchProtection.create` → `repo.internal`)
- **Issue:** `map_rule` required `i64` for `required_approving_review_count`; Postgres INTEGER is INT4
- **Fix:** Try `i32` first, fall back to `i64` (SQLite)
- **Commit:** `0f2b269`

**3. [Rule 2 - Critical] Smoke must set `enforce_admins`**
- **Found during:** Task 1 smoke design
- **Issue:** Bootstrap admin PAT is `Capability::Admin` and bypasses reviews when `enforce_admins=false`
- **Fix:** Create rule with `enforce_admins: true` so D-PKG-03 denial is observable for the owner PAT
