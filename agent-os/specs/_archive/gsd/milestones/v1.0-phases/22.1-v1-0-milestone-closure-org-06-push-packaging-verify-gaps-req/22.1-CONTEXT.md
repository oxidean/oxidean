<decisions>
## Implementation Decisions

### A — ORG-06 packaging & fail-open
- **D-PKG-01:** Full audit close — build and copy `oxidean-protection-hook` into the API Docker image; set `OXIDEAN_PROTECTION_HELPER` in Compose; Smart HTTP falls back to `default_helper_path()` when env unset; SSH `receive-pack` passes helper + DB + repos (+ actor capability) env into hooks so update hooks can run — **Reversibility:** costly — image + Compose + HTTPS/SSH receive paths
- **D-PKG-02:** When the helper is missing or not executable: **fail-closed in production** (`OXIDEAN_ENV=production` or equivalent); **fail-open (or soft warn) in development** so local git without the helper still works — **Reversibility:** reversible
- **D-PKG-03:** Prove in shipped image via **Compose smoke** — after bring-up, a protected-branch direct push is denied over HTTPS; include SSH when the smoke stack exposes SSH TCP — **Reversibility:** reversible
- **D-PKG-04:** On API boot, **sweep `OXIDEAN_REPOS_DIR`** and install missing update hooks on existing bare repos (upgrade safety net beyond lazy reconcile) — **Reversibility:** costly — boot path / large repos_dir walks

### B — Fork / `clone_bare` hooks
- **D-FORK-01:** Fix the audit WARNING in this phase — forks must get protection hooks — **Reversibility:** reversible
- **D-FORK-02:** Install hooks **inside `clone_bare`** (same pattern as `init_bare`) so every bare copy gets hooks; boot sweep remains a safety net for older forks — **Reversibility:** reversible
- **D-FORK-03:** Prove with unit/integration assert that `hooks/update` exists after `clone_bare` (reuse `hooks_installed` from Phase 13) — **Reversibility:** reversible
- **D-FORK-04:** If hook install fails after a successful `clone_bare`, **fail the fork** and compensate/rollback like other post-insert storage errors — **Reversibility:** reversible

### C — VERIFICATION & Nyquist
- **D-VER-01:** **Hybrid backfill** — full `/gsd-verify-work` (or equivalent thorough VERIFICATION) for phases **13** and **22**; evidence-based VERIFICATION from SUMMARYs + integration wiring for **01, 02, 03, 11.1, 12, 16, 17, 18, 21** — **Reversibility:** reversible
- **D-VER-02:** Include **`/gsd-validate-phase` for 8, 14, 15, and 20** in this phase (Nyquist / coverage honesty) — **Reversibility:** reversible
- **D-VER-03:** Lightweight VERIFICATION may be **`passed`** when evidence supports the phase goal (residual caveats OK in the body). If real gaps are found → **`gaps_found` / `partial`** and **block milestone until fixed**. Do **not** use `human_needed` — **Reversibility:** reversible
- **D-VER-04:** **Package ORG-06 first**, then thoroughly verify **13** and **22**. Other lightweight VERIFICATIONs may run in parallel anytime — **Reversibility:** reversible

### D — WINDOWS & REQUIREMENTS hygiene
- **D-HYG-01:** **Mass-waive** clearly obsolete Wave 0 WINDOWS stubs whose owning plan already shipped; reason must cite superseded plan; spot-check a sample — **Reversibility:** reversible

- **D-HYG-03:** For non-stub WINDOWS (deviations, skipped-tests, unrun-verify): waive historical noise; **keep only entries that still describe current debt** — **Reversibility:** reversible
- **D-HYG-04:** Leave **ORG-06 `[x]`** in REQUIREMENTS; fix packaging this phase; honesty via Phase 13 VERIFICATION + re-audit — **Reversibility:** reversible
