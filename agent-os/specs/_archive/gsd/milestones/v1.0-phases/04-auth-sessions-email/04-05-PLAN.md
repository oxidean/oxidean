<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → WorkOS / OIDC IdP → `/api/auth/*/callback` | Authorization codes and state/PKCE verifiers cross external IdP boundary |
| Admin-configured OIDC issuer URL → discovery HTTP | SSRF risk if issuer is attacker-controlled |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-15 | Spoofing | OIDC/WorkOS callback | mitigate | Validate `state` (and OIDC `nonce`) against server-side pending auth store (in-memory map keyed by state, TTL 10m); reject missing/mismatch; use PKCE |
| T-04-16 | Spoofing / SSRF | OIDC issuer discovery | mitigate | Require `https://` issuer; reject hosts `localhost`, `127.0.0.1`, `169.254.0.0/16`, `10.0.0.0/8`, `metadata` — document residual risk if admin is compromised (accept residual for ASVS L1 with admin-only settings) |
| T-04-17 | Elevation of privilege | WorkOS sealed session | mitigate | Do **not** use WorkOS sealed cookies as app session — always mint Oxidean `sessions` row (D-07) |
| T-04-18 | Information disclosure | IdP errors | mitigate | Log details server-side; browser redirect to `/login?error=sso` with generic message |
</threat_model>
