# Specs

Chronological record of spec'd work for this product. New work is shaped
with the `agent-os-shape-spec` skill and lands as `YYYY-MM-DD-HHMM-<slug>/`
folders (`plan.md`, `shape.md`, `standards.md` when applicable,
`references.md`).

Records dated before the Agent OS migration (2026-10-30) are **imports** of
prior spec-framework work — the v1.0 GSD milestone and the AI-DLC intents —
so the history is discoverable here, not only in the raw archive. Their
`plan.md` files summarize what shipped; full per-stage artifacts stay
read-only under [`_archive/`](_archive/) (`gsd/` phase records, `aidlc/`
intent records).
