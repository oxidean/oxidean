## Accomplishments
- Rewrote `styles.css` onto the complete ShadCN semantic token set (background, foreground, card, popover, primary, secondary, muted, accent, destructive, border, input, ring) in both `:root` and `.dark`, with `--primary` as the cool/left blue family and `--secondary` as the warm/right orange family; legacy `--color-accent-cool`/`--color-accent-warm` fully removed from the stylesheet

- Added a dependency-free superellipse (n=5, macOS app-icon curve) SVG generator and committed its output, plus a shared `OxideanMark` component that clips `/oxidean-mark.png` to that squircle with no padded plate and `alt="Oxidean"` in both themes

## Decisions Made
- Hand-authored the three `components/ui/*` files directly to the plan's exact contracts rather than running the shadcn CLI, since the CLI's generated output shape is not guaranteed to match the interface wave-2 plans import against (`buttonVariants`, the full `Select*` export list). No new dependency was introduced either way (`class-variance-authority`, `@base-ui/react`, `lucide-react` were already in `apps/web/package.json`); `bun.lock` is untouched.
- Left `squircle.svg` as a committed artifact regenerated by a script rather than a build-time transform, per the plan's explicit note that 03-05's icon generation and the CSS mask both need to read it from `public/`.
