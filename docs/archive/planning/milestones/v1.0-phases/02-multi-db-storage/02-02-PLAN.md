<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `oxidean-db` → Postgres / MySQL / SQLite engine | Migration DDL and probe SQL text with bound parameters cross into the engine |
| `migrations/{postgres,mysql,sqlite}/` → target database schema | Files in the repo mutate operator schemas on boot or on demand |
| `migrate` binary stdout/stderr → operator terminal and CI logs | Failure paths could echo the connection string |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information disclosure | migrate/probe error strings and CLI output | mitigate | Reuses `redact_url()` from 02-01: the `migrate` binary prints only `redact_url(&url)`, and probe errors are a fixed `"db probe failed: {e}"` with no URL content; the CLI acceptance criterion asserts no password appears in its output |
| T-02-02 | Tampering | per-dialect migration drift | mitigate | `migration_parity` unit test asserts identical filename sets across `migrations/{postgres,mysql,sqlite}` — a migration added to one dialect only fails the build |
| T-02-03 | Tampering | SQL injection into probe statements | mitigate | Probe SQL is a fixed string per dialect with only bound placeholders (`$1` / `?` / `?1`); no `format!()` of any caller-supplied value into SQL |
| T-02-13 | Tampering | migrating a populated database | mitigate | `--assert-empty` counts user tables (excluding `_sqlx_migrations`) and refuses a non-empty target; `--force-empty` is an explicit operator opt-in that still only runs migrations and never issues DROP/TRUNCATE (D-16). Same threat ID as 02-04, where the operator-facing `db-switch-dialect.sh` delegates to this binary rather than reimplementing the check |
</threat_model>

New `crates/oxidean-db/src/probe.rs` with `pub async fn probe(pool: &DbPool, dialect: Dialect) -> Result<DbProbeResponse, String>`: a single-row upsert on `id = 1` followed by a read-back, with these exact statements (RESEARCH pitfalls 4 and 5 — placeholders and upsert syntax differ per dialect):

   - Postgres upsert:
```sql
INSERT INTO instances (id, dialect, probe_count, probed_at)
VALUES (1, $1, 1, now())
ON CONFLICT (id) DO UPDATE
SET probe_count = instances.probe_count + 1,
    dialect = EXCLUDED.dialect,
    probed_at = now()
```
   - Postgres read:
```sql
SELECT dialect,
       probe_count,
       to_char(probed_at AT TIME ZONE 'UTC', 'YYYY-MM-DD"T"HH24:MI:SS"Z"') AS probed_at
FROM instances WHERE id = 1
```
   - MySQL upsert (alias form — `VALUES()` is deprecated in MySQL 8.0.20+, and Compose/CI use `mysql:8.4`):
```sql
INSERT INTO instances (id, dialect, probe_count, probed_at)
VALUES (1, ?, 1, NOW()) AS new
ON DUPLICATE KEY UPDATE
  probe_count = instances.probe_count + 1,
  dialect = new.dialect,
  probed_at = NOW()
```
   - MySQL read:
```sql
SELECT dialect,
       probe_count,
       DATE_FORMAT(probed_at, '%Y-%m-%dT%H:%i:%sZ') AS probed_at
FROM instances WHERE id = 1
```
   - SQLite upsert:
```sql
INSERT INTO instances (id, dialect, probe_count, probed_at)
VALUES (1, ?1, 1, strftime('%Y-%m-%d %H:%M:%S','now'))
ON CONFLICT(id) DO UPDATE SET
  probe_count = instances.probe_count + 1,
  dialect = excluded.dialect,
  probed_at = strftime('%Y-%m-%d %H:%M:%S','now')
```
   - SQLite read:
```sql
SELECT dialect,
       probe_count,
       strftime('%Y-%m-%dT%H:%M:%SZ', probed_at) AS probed_at
FROM instances WHERE id = 1
```

   Bind `dialect.as_str()` as the only parameter (D-10 stamp). Decode with `sqlx::query` + `Row::try_get::<String>("dialect")`, `try_get::<i64>("probe_count")`, `try_get::<String>("probed_at")` — timestamps are formatted in SQL so no chrono decoding is needed on any dialect. All errors map through `format!("db probe failed: {e}")` with no URL or credential content (T-02-01).
3. Expose `pub async fn probe(&self) -> Result<DbProbeResponse, String>` on `Database`; when `pool` is `None` return `Err("database not configured".into())`.
4. Add `oxidean-core` re-export usage in `src/lib.rs` (`pub use oxidean_core::DbProbeResponse;`) so downstream crates import one path.
