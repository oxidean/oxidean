<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| API → SMTP / Resend | Outbound email crosses to third-party networks with credentials from ENV |
| Operator ENV → EmailSender | Secrets `OXIDEAN_SMTP_URL`, `OXIDEAN_RESEND_API_KEY` never logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04 | Information disclosure | email logs / errors | mitigate | LogSink logs to/subject/body only via `tracing::info!(target: "oxidean.mail", ...)`; never log SMTP URL password or Resend API key; redact in error strings |
| T-04-05 | Tampering | email header injection | mitigate | Use lettre typed `Mailbox` parsing for To/From; reject invalid addresses before send; Resend JSON uses structured fields not raw headers |
| T-04-06 | Spoofing | From address | accept | Operator configures From via ENV/settings; Phase 4 does not SPF/DKIM — ops concern |
</threat_model>
