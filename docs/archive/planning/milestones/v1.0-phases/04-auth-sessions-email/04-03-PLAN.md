<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser ↔ API cookie `oxidean_session` | Opaque session id crosses trust boundary on every credentialed request |
| Password plaintext (request) → Argon2 → DB | Credential material must never be logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-07 | Elevation of privilege | session cookie | mitigate | HttpOnly; no JS access; store only SHA-256(token) in DB; 32+ byte CSPRNG token; SameSite=Lax (CSRF Phase-4 discretion) |
| T-04-08 | Elevation of privilege | session fixation | mitigate | Always mint a new session id on login/signup; never reuse anonymous cookies |
| T-04-09 | Information disclosure | password handling | mitigate | Argon2id via `argon2` crate; never `tracing` password or hash; verify uses PasswordVerifier |
| T-04-10 | Tampering | cookie Secure flag | mitigate | `Secure` when `OXIDEAN_ENV` ∉ `{development,dev}`; Path=/; no Domain attribute (Vite proxy pitfall) |
</threat_model>
