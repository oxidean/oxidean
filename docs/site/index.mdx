Oxidean is a **self-hostable code forge**: git hosting, pull requests,
issues, CI actions, and package registries in one product. The same
codebase runs Oxidean Cloud and installs on your own machines. There is
no feature fork between the hosted service and what you run yourself.
MIT-licensed.

On the mainline today: Smart-HTTP + SSH git hosting with commit-signature
verification, pull requests with merge controls and branch protection
(including a GitHub-style PR experience behind an experiment flag), issues,
CI actions on self-hosted runners with cron triggers, reusable workflows,
artifacts, caching, environments, status badges, and OIDC, OCI/npm/generic
package registries, Git LFS, releases, forks, repository mirroring (push,
pull, and two-way), organizations and collaborators, milestones, discussions,
repo wikis and project boards, notifications and webhooks, per-repo unit
toggles, search and explore, OIDC / WorkOS SSO, an admin
console with a first-run setup wizard, a REST API with OpenAPI spec, an MCP
server for agents, the `ox` CLI, and Postgres / MySQL / SQLite backends.
Deploy as a compose bundle, the Helm chart for Kubernetes (with bundled
RustFS or SeaweedFS object stores), or the hosted cloud. See
[what's shipped](https://github.com/oxidean/oxidean#readme) and
[ROADMAP.md](https://github.com/oxidean/oxidean/blob/main/ROADMAP.md) for
the rest of the distance to forge parity.
